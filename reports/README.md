# Relatórios

Registre somente execuções reais, com commit, ambiente, comandos, data da execução e limitações. Relatórios JSON locais são ignorados pelo Git; publique apenas resultados sanitizados e revisados.

Não inclua conversas privadas, entradas reais de usuários, tokens ou informações da máquina que não sejam necessárias à medição. Não use resultados hipotéticos como baseline.
